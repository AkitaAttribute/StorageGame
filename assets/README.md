# Model assets (CC0)
With Python 3 and Node.js 22 installed, run `python tools/fetch_assets.py` before opening the project. The workflow does this automatically. The facility models are converted using glTF Transform's dequantize command because the original files require an extension not supported by Godot.
- Facility and animated unit: https://3dassets.dev/packs/self-storage-facility-and-loading-bay — CC0 1.0, AI-assisted per creator disclosure. Starter scene is static.
- Rogue: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 — Kay Lousberg, CC0 1.0, rigged and animated. Pinned to commit 672074b73ba276876a19e8816ecdc5241817ab47.

- Sendagaya Shino: https://vroid.pixiv.help/hc/en-us/articles/360013482714-Sendagaya-Shino — Pixiv VRoid Studio official CC0 model. Original VRM 0.x from https://github.com/madjin/vrm-samples pinned to e16eb187100149a315ad92c3c9968f1d5baa6c7d. The linked VRoid Hub edition is VRM 1.0; the build uses the older freely downloadable original of the same character. Import uses standard glTF materials, without the VRM MToon shader or spring-bone physics. Existing KayKit animations are retargeted at runtime.

- Locomotion donor: Quaternius Universal Animation Library (CC0), humanoid mannequin and in-place walk/idle clips from https://github.com/call-me-sensei-app/toonlab at 2e354c52e5539e33fb3d8f339645b47e1ac937ca. Replaces the stylized KayKit locomotion donor. https://quaternius.com/packs/universalanimationlibrary.html

- Household refrigerator and desk: Quaternius Ultimate Home Interior Pack (CC0), from https://github.com/trebeljahr/quaternius-showcase pinned to 0128ca510d653bb04d6d1e4885bd8890b5050b4f. Original pack: https://quaternius.com/packs/ultimatehomeinterior.html. Screwdriver is original procedural geometry in scripts/household_props.gd.

- Build 23 household upgrades: Metal Office Desk (Ulan Cabanilla, CC0) https://polyhaven.com/a/metal_office_desk and Flathead Screwdriver (Dylan Detwiller, CC0) https://polyhaven.com/a/flathead_screwdriver. Official Poly Haven 1K glTF and texture dependencies, bundled to GLB. Boom Box by Microsoft, 2017 (CC0 1.0 Universal), distributed in the Khronos glTF Sample Assets repository: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/BoomBox ; https://creativecommons.org/publicdomain/zero/1.0/ . Imported, scaled and given game collision/physics. The original Quaternius fridge is retained; the lamp and procedural screwdriver are superseded.
